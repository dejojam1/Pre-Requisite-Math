    Section 1.2 Adding and Subtracting Fractions

    When adding or subtracting fractions with the same denominator (a common denominator), the numerators can be added or subtracted;
    \begin{equation*} \frac{a}{c}\pm\frac{b}{c}=\frac{a\pm b}{c}. \end{equation*}
    🔗

    Example 1.2.1. Adding and Subtracting Fractions with a Common Denominator.

    Calculate \(\frac{5}{7}+\frac{4}{7}\) and \(\frac{5}{7}-\frac{4}{7}\text{.}\)
    🔗
    Solution.
    Since these fractions have the same denominator, we can add the numerators. The denominator remains the same, so
    \begin{equation*} \frac{5}{7}+\frac{4}{7}=\frac{5+4}{7}=\frac{9}{7}. \end{equation*}
    Similarly,
    \begin{equation*} \frac{5}{7}-\frac{4}{7}=\frac{5-4}{7}=\frac{1}{7}. \end{equation*}
    🔗
    🔗
    🔗

    🔗
    What if the fractions have different numbers in the denominator? Then we first need to write the fractions in a different (but equivalent) form so that they have a common denominator. A typical choice of common denominator is the least common multiple (LCM) of the two denominators, but an easy choice to make is to use their product. We multiply both the numerator and denominator of each fraction by the other denominator;
    \begin{equation*} \frac{a}{c}\pm\frac{b}{d}=\frac{ad}{cd}\pm\frac{bc}{dc}. \end{equation*}
    Since \(cd=dc\text{,}\) these fractions have a common denominator, and so we can add or subtract as in the example above.
    🔗

    Example 1.2.3. Adding and Subtracting Fractions with Different Denominators.

    Calculate \(\frac{5}{8}+\frac{4}{7}\) and \(\frac{5}{8}-\frac{4}{7}\text{.}\)
    🔗
    Solution.
    These fractions have different denominators, 7 and 8. We first write them over a common denominator, \(7\times 8=56\text{,}\)
    \begin{equation*} \frac{5}{8}+\frac{4}{7}=\frac{5\times 7}{8\times 7}+\frac{4\times 8}{7\times 8}=\frac{35}{56}+\frac{32}{56}. \end{equation*}
    Now they have the same denominator, and so we can add the numerators,
    \begin{equation*} \frac{35}{56}+\frac{32}{56}=\frac{35+32}{56}=\frac{67}{56}. \end{equation*}
    Similarly,
    \begin{equation*} \frac{5}{8}-\frac{4}{7}=\frac{35}{56}-\frac{32}{56}=\frac{35-32}{56}=\frac{3}{56}. \end{equation*}
    🔗
    🔗
    🔗

    Example 1.2.5. Using the LCM.

    Calculate \(\frac{3}{4}+\frac{5}{8}\text{.}\)
    🔗
    Solution.
    These fractions have different denominators, 4 and 8. We could use a common denominator of \(4\times 8=32\text{,}\) but we can instead use any common multiple of 4 and 8. The LCM of 4 and 8 is 8, and so we write the fractions over a common denominator of 8.
    🔗
    This requires multiplying the numerator and denominator of the first fraction by 2,
    \begin{equation*} \frac{3}{4}+\frac{5}{8}=\frac{3\times 2}{4\times 2}+\frac{5}{8}=\frac{6}{8}+\frac{5}{8}. \end{equation*}
    Now they have the same denominator, and so we can add the numerators,
    \begin{equation*} \frac{6}{8}+\frac{5}{8}=\frac{6+5}{8}=\frac{11}{8}. \end{equation*}
    🔗
