    Section 3.3 Exponential Functions

    Exponential functions have the form \(a^x\text{,}\) where a is called the base. In this course we’ll be dealing with situations where \(x\) is an integer. Much like \(3^2=3\times 3\) and \(4^3=4\times 4\times 4\text{,}\) if we have \(2^x\) we are multiplying \(x\) copies of 2.
    🔗
    There are a few exponent rules that you will need to be familiar with. The first ones are for multiplying and dividing exponential terms with the same base:
    🔗
    \begin{equation*} a^xa^y=a^{x+y}, \end{equation*}
    \begin{equation*} \frac{a^x}{a^y}=a^{x-y}. \end{equation*}
    We also need to know what to do when there are multiple powers. In particular,
    🔗
    \begin{equation*} (a^x)^y=a^{xy}=(a^y)^x. \end{equation*}
    Finally, if two exponential functions with the same base are equal, then the powers must be equal, so if \(a^x=a^y\text{,}\) then \(x=y\text{.}\)
    🔗

    Example 3.3.1. Solving Exponential Equations.

    Solve the equation \(2^{2x-1}4^x=8^x\text{.}\)
    🔗
    Solution.
    The rules above required the bases to be the same. However, note that \(4=2^2\) and \(8=2^3\text{.}\) If we make those replacements, then we will obtain the same base in all three terms:
    🔗
    \begin{equation*} 2^{2x-1}(2^2)^x=(2^3)^x. \end{equation*}
    Now we can use the rule regarding powers of powers to get
    🔗
    \begin{equation*} 2^{2x-1}2^{2x}=2^{3x}. \end{equation*}
    Now the left-hand-side has a product of two exponential functions with the same base, so we may add the powers:
    🔗
    \begin{equation*} 2^{(2x-1)+2x}=2^{3x}. \end{equation*}
    From here, we know that the powers must be equal, so
    🔗
    \begin{equation*} (2x-1)+2x=3x. \end{equation*}
    This is a linear equation, which we can solve:
    🔗
    \begin{equation*} 4x-1=3x, \end{equation*}
    \begin{equation*} x=1. \end{equation*}
    🔗
    🔗
